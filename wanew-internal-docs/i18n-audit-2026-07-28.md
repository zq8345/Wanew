# #69 三语母语级质检报告(en / es / pt)

**性质**:只读审计,**没有改任何东西**。问题清单在下面,按"值不值得修 × 修起来多大"排了序,等总工分批派。
**日期**:2026-07-28 · 数据全部来自当次实跑扫描器 + 生产 curl,不是估计。

---

## 0. 一句话结论

**es 的质量是好的,pt 的质量没被任何闸看着,而两者共同的真问题不是"翻得好不好",是"根本没有那一页"。**

- 翻译质量层面:es 有术语闸强制、当前 **0 命中**;英文残留 **2 处**。
- pt 没有对应的术语闸,英文残留 **260 处可见文本 + 92 个英文链接**。
- 但最大的一项是覆盖:**en 95 页 / es 28 页 / pt 28 页** —— 67 页只有英文。

### 1.1 🔴 最值得先修的一条:`/type/` 在两个 SEO 语种缺席

```
cables/mounts/power/networking/cases
  en = 有    zh(内部,noindex) = 有    es = 无    pt = 无
```
生产实测:`/es/type/cables/` → **404**、`/pt/type/cables/` → **404**、`/type/cables/` → 200。

**为什么这条排第一**:
- 它**不是翻译量的问题** —— 这 5 页的正文是卡片网格,文案早就在 catalog 里有 es/pt 值了。
- 它造成的是:**es/pt 访客完全没有"按形态浏览"这条轴**,而英文站和**连内部用的 zh 都有**。两个真正要做 SEO 的语种,反而是唯一没有的。
- 目前 es 页面里指向 `/type/` 的链接 = **0**,所以现在不是死链、是**根本进不去**。修完才需要同步接链接。

### 1.2 58 篇 guides 只有英文
这是已知且**已被有意识接受**的债(总工/Joe 当时选了"留现状 + 诚实角标"):本地化列表页会显示英文标题并挂 `card.lang_badge`(在 pt = "em inglês")。
→ **建议维持现状**,除非要立项做内容本地化。它也是下面 pt 泄漏数字的主要来源(见 §2.2)。

## 2. 无漂移 / 术语一致

### 2.1 es —— 有闸,当前干净
`es-glossary-check` 强制:禁用词 11 条 + 术语 variants 20 条 + 数字格式。
**当次实跑:扫 914 个 es-MX 值,0 命中。** 术语一致性在 es 是**被机器强制**的,不靠人自觉。

### 2.2 pt —— ⚠️ 没有对等的闸(结构性不对称)
仓里有 `es-glossary-check.mjs`,**没有 pt 对应物**。也就是说:
- es 漂了会红;**pt 漂了没有任何东西会响**。
- `pt-leak-scan` 报 **类① 可见英文文本 260 处 · 类② 英文链接 92 处**,但它抓的是"还是英文",**不是**"翻成了不一致的葡语"。
- 这 260 里**很大一部分是 §1.2 那 58 篇英文文章的卡片标题**(有诚实角标),属于已接受的债;但**它和真正的漏译混在同一个数字里**,导致这个数字**不能用来判断 pt 质量**。

**建议**(不改,只提):把 pt 泄漏拆成「已接受(英文文章卡片)」与「真漏译」两类分别计数,否则这个指标永远既不达标也不刺眼 —— 一个永远红的门,最后会被所有人略过。

## 3. 翻译质量(母语度)

**能机器证的部分**:
- es 有术语表 + 禁用词(如 `carro/coche→` 判为西班牙用语、`móvil` 名词义、`vídeo` 带重音、小数逗号),**当前全绿**;方向是明确对着**墨西哥西语**校的,不是泛西语。
- 今天这一批还给 es 闸补上了**复数形匹配**与**同形异义**处理(`instalaciones móviles` = 形容词,不误判成"手机")。

**机器证不了的部分(如实说)**:
- **动词变位式的 usted**(`Obtenga`/`Pruebe`)不含 "usted" 三个字母,闸抓不到 —— 这是**闸自己在文件里承认的洞**。
- "读起来像不像母语人写的"**没有任何自动手段能判**。
- → **要真回答"母语级"这一问,必须有一个母语读者读一遍**。我能保证的是"没有已知错误",**不能**保证"读着地道"。这两件事不是一回事,不该混着报。
